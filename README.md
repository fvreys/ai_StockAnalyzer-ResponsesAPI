This is a specialized assistant for analyzing and visualizing stock market data, which uses the OpenAI Responses API.
The model is enrichted with external tools for knowledge retrieval from a MCP server and a code interpreter for data analysis and visualization. 
We used prompt engineering strategies to guide the assistant in processing stock data and generating visual plots.

More detail on: https://hyperskill.org/projects/558

BACKGROUND
LLMs can do more than chat: they can help you explore data, run calculations, and present insights clearly. 
This is a Stock Analyzer tool that makes it easier to turn raw market data into understandable trends and visuals. 
We have a practical, end-to-end solution that leverages LLMs to support real stock analysis workflows.
